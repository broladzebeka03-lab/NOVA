# NEXUS - Next-Gen Web Application

თანამედროვე, პრემიუმ დიზაინის მქონე ვებ-გვერდი შექმნილი სუფთა **HTML5**, **CSS3** და **Vanilla JavaScript**-ით.

## 🌟 შემადგენელი სექციები

1. **Loading Screen (Preloader)**:
   - ანიმირებული ლოგო, პულსირებადი მანათობელი რგოლები.
   - დინამიკური პროგრეს-ბარი და პროცენტული მთვლელი (0%-დან 100%-მდე).
   - ეტაპობრივი სისტემური სტატუსები.
   - გამოსვლის გლუვი ანიმაცია (`fade-out` & slide reveal).
   - ფუტერში არსებული ღილაკი **"Replay Loading Screen"** ანიმაციის ხელახლა საჩვენებლად.

2. **Hero სექცია**:
   - ნეონის და გრადიენტული განათებები (`radial-gradient` glow & grid mesh).
   - მთავარი სათაური და ქვესათაური.
   - ორმაგი CTA ღილაკები ("Explore Features", "Watch Overview").
   - 3D-სტილის ცოცხალი ინტერაქციული Dashboard Mockup, ლაივ სპარკლაინებითა და ტერმინალით.
   - მცურავი ჰოლოგრაფიული ბარათები ("Real-Time Sync", "End-to-End Encrypted").
   - რეალური მეტრიკების ზოლი (99.99% Uptime, 120ms Global Latency, 45K+ Deployments).

3. **About სექცია**:
   - კომპანიის მისიისა და ტექნოლოგიური მიზნების ბარათი.
   - უპირატესობების სია მონიშვნის იკონებით.
   - 4 ინტერაქციული სტატისტიკური ბარათი ჰოვერის ეფექტებით.

4. **Features სექცია**:
   - 6 დეტალური შესაძლებლობა:
     - *Quantum Velocity Engine*
     - *Adaptive AI Automation*
     - *Zero-Trust Shielding*
     - *Telemetry & Deep Analytics*
     - *Universal API Fabric*
     - *Edge Mesh Synchronization*
   - ბარათებზე თაგვის მიყვანისას (Hover) განათებისა და აწევის ეფექტები.

5. **Contact ("conect") სექცია**:
   - საკონტაქტო ინფორმაციის პანელი (იმეილი, ტელეფონი, ლოკაცია, სოციალური ქსელები).
   - სრულფასოვანი ფორმა ვალიდაციით (Full Name, Work Email, Inquiry Subject, Message).
   - შეცდომების ცოცხალი მინიშნება არასწორ შეყვანაზე.
   - ღილაკზე გაგზავნისას ანიმირებული სპინერი (`loading state`).
   - გაგზავნის შემდეგ გამოჩენილი პრემიუმ შეტყობინება (**Toast Notification**).

6. **დამატებითი ფუნქციები**:
   - **Sticky Navigation**: სქროლისას მინის ეფექტის მქონე (`glassmorphism`) ფიქსირებული მენიუ.
   - **ScrollSpy**: აქტიური გვერდის ბმულის ავტომატური განათება სქროლვისას.
   - **Mobile Menu**: ადაპტირებული ჰამბურგერ-მენიუ მობილურებისთვის.
   - **Back to Top**: გვერდის სათავეში დაბრუნების მცურავი ღილაკი.
